# Intelligent Intake v2.24
Adds column semantic mapping, unit inference, mapping confidence/human-confirmation flags, generic independent reconciliation expansion, canonical evidence extraction for AR/AP/workforce/operations, and fail-closed intake assessment. It deliberately does not invent invoice-level or transaction-level fields where a workbook only contains aggregate customer/supplier schedules.

Qualification fixtures: Unknown Workbook 1 and 2. Embedded reconciliation formula/status cells are never authoritative; controls are independently recalculated where underlying/supporting evidence is available.
