# Profit Doctor v2.37 — Upload-to-Report Demo

This milestone joins the existing components into one reproducible demonstration path:

**Uploaded workbook → intake profiling → semantic mapping → reconciliation → canonical hand-off → primitives → diagnostics → FD reasoning → economics → management attention → opportunity register → typed product view + drill-down exports.**

The runner preserves a copy of the uploaded source, records its SHA-256 hash, creates a run-scoped SQLite demonstration database, and exports `review.json`, management-priority drill-downs, diagnostic drill-downs and `manifest.json`.

This is a demonstration/orchestration milestone, not production upload infrastructure. It does not add diagnostic 57, does not infer missing evidence, and does not convert control discrepancies, capacity or exposures into unsupported savings.
