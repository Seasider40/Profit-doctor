# v2.40 — D15 CRM / Pipeline / Win-Loss

D15 is now a first-class canonical evidence domain. The local qualification schema persists CRM opportunities, stage history, activities and deterministic analysis results.

## Canonical semantics
An opportunity carries source key, name, customer (where mapped), owner, created/expected/actual close dates, stage, OPEN/WON/LOST status, amount/currency, optional CRM-entered probability and optional lost reason. Closed opportunities require an actual close date. Probability must be 0–100. Invalid evidence fails closed.

## Deterministic intelligence
The engine can describe open pipeline value, observed closed win rate, CRM-weighted pipeline where CRM probabilities exist, open value past expected close date, and owner concentration. These are evidence summaries, not new financial facts.

## Guardrails
- Pipeline is not recognised revenue.
- CRM-entered probability is not a Profit Doctor probability.
- Weighted pipeline is not a forecast.
- Historical win rate is not a prediction for open opportunities.
- Win/loss reason or association does not prove causality.
- No new diagnostic test has been added: the 56-test development freeze remains intact. D15 enriches forward-looking commercial evidence and future product reasoning.
